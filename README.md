# Automated Server Collector (ACS)

## Что это?
Система автоматического сбора серверных конфигураций из публичных репозиториев GitHub.

## Как работает?
1. Ищет репозитории по 50+ ключевым словам
2. Выбирает случайные репозитории для парсинга
3. Скачивает конфигурационные файлы
4. Анализирует на наличие серверной информации
5. Сохраняет историю изменений
6. Генерирует отчёты
7. Всё автоматически обновляется каждые 2 часа

## Установка
1. Создай репозиторий на GitHub
2. Загрузи все файлы этого проекта
3. Добавь токен в GitHub Secrets (настройки репозитория → Secrets)
4. Включи GitHub Actions

## Структура
- `collected_servers/` - собранные файлы
- `history/` - история изменений
- `reports/` - отчёты о работе
